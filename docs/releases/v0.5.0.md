The End.

## What's new

- **The End.** The dimension switch now has the End, with its biomes
  (the main island, highlands, midlands, small islands and barrens) in
  their own colors. The void between the islands is drawn darker, so the
  map shows the shape of the main island and the outer islands.
- **End cities** are on the map and in the inspector, checked against the
  End terrain exactly like the game does.
- **The seed finder searches end cities**, for example "an end city within
  1500 blocks of the End's 0, 0", alone or together with Overworld and
  Nether filters. End filters are measured from the End's 0, 0.

Every new piece is verified against the real game, bit for bit, by the
oracle tests: the End's simplex noise and island heights, 12,000 End
biomes, the End terrain, the island density at arbitrary blocks, and every
end city attempt and generation point on several seeds.

The island shapes on the map come from the islands' density, so their
edges are approximate; biomes and structures are exact. Only mineshafts are
left unchecked (planned for 0.6).

Matches Minecraft: Java Edition 26.3.
