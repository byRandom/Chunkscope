A seed finder query you can copy and paste.

## What's new

- **The finder's query as text.** The top of the seed finder shows the
  query in a short text form, for example
  `center=spawn villages:300:2 end_cities+ship:1000 biome=plains,meadow`.
  Copy it to share a search, paste one to load it, or edit it directly:
  the form follows the text and the text follows the form. Text that does
  not parse says what is wrong.
- **Several biomes at the center.** The biome filter now takes any number
  of biomes (a match needs one of them). Settings saved by 0.6.0 still
  load.
- **Copy all results.** A button next to the results copies every match,
  one line per seed: the seed, the center, its biome and the structures
  found.
- **The command-line example `find` takes the same query**, so it can now
  search Nether and End structures and several biomes too. Its `--zero`
  and `--biome` options become `center=zero` and `biome=...`.

No change to world generation: the map and the finder find exactly what
0.6.0 found.

Matches Minecraft: Java Edition 26.3.
