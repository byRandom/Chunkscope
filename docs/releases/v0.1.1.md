A bug-fix release.

## Fixed

- **Pasting into text fields works.** In 0.1.0 the app was built without
  clipboard support, so Ctrl+V did nothing in the seed and "Go to" fields,
  and "Copy /tp" copied nothing.
- The link in the About panel opens in the browser again.

## Added

- A button next to the seed copies the numeric seed (handy for text seeds).
- Right-click the map to copy the coordinates under the pointer, copy a
  `/tp` command for them, or center the map there.
- The inspector keeps the last position under the pointer when it leaves the
  map, so its values can be selected and copied with Ctrl+C.
