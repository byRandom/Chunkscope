A clearer map for dense layers.

## What's fixed

- **Layers that are too dense for the current zoom now say so.** Some
  structures are attempted very close together (Nether fossils every 2
  chunks, mineshafts in every chunk), so the map only draws them when
  zoomed in far enough. Until now such a layer stayed blank without any
  explanation; its row now reads "zoom in (150%+)", with the zoom it needs.
- Nether fossils only generate in soul sand valleys, so that is where they
  show up once zoomed in.

Matches Minecraft: Java Edition 26.3.
