End city ships.

## What's new

- **Which end cities have a ship.** End cities with a ship (and so an
  elytra) get a green dot on the map; the inspector says "Ship: Yes
  (elytra)" or "No", and so does the tooltip.
- **The seed finder can require a ship:** an End cities filter has a "With
  a ship (elytra)" option.
- Selected markers now read "End city", not "End citie".

Chunkscope builds each city's pieces (towers, bridges, houses and the ship)
exactly like the game does. The oracle tests compare whole piece lists with
the real game, piece by piece, for 600 cities (32,751 pieces, 335 with a
ship) and for 40 cities that generate in a real world.

Matches Minecraft: Java Edition 26.3.
