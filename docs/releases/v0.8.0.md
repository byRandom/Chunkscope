Stable formats: what Chunkscope saves, prints and accepts will keep working.

## What's new

- **The formats are frozen and documented** in `docs/FORMATS.md`: the
  finder's query text, the one-line result, the command line's JSON and the
  settings file, each with what it promises. Queries keep parsing with the
  same meaning, JSON fields are only added, and settings from older versions
  keep loading. Tests pin the settings file's saved form and the structure
  ids, so a change cannot slip in unnoticed.
- **Settings from a newer version are not read.** If you go back to an older
  Chunkscope, it starts with the defaults instead of guessing what newer
  fields mean (before, it loaded them field by field).
- **No signed builds, on purpose.** Signing costs money and Chunkscope is
  free to use, so the binaries stay unsigned, with checksums. The README
  explains how to run them on Windows and macOS.

No change to world generation: the map and the finder find exactly what
0.7.0 found.

Matches Minecraft: Java Edition 26.3.

Windows, SmartScreen may ask for confirmation ("More info", then "Run
anyway"); on macOS, run `xattr -d com.apple.quarantine chunkscope` first.
On Linux the app needs the usual X11 or Wayland libraries.
