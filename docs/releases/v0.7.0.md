Checked against the real game on hundreds of random seeds, and a command line.

## What's new

- **Large-scale verification.** A new "wide" check runs the game's own
  classes on random seeds in all three dimensions and compares every answer
  with Chunkscope: biomes, terrain heights, every structure attempt in an
  area (with the ones the game rejects), end city ships, the world spawn
  and strongholds. The first run, 200 seeds, compared about 400,000 values
  and found no difference. It runs every week and before each release
  (see `docs/PARITY.md`).
- **`chunkscope-cli`, a command line tool.** It comes in the archive next
  to the app and replaces the old examples: `biome`, `height`, `spawn`,
  `structures`, `find` and `targets`, each with `--json` for scripts and
  `--dimension` where it applies. `find` takes the same query text as the
  app's finder. Everything is in `docs/CLI.md`.

No change to world generation: the map and the finder find exactly what
0.6.1 found.

Matches Minecraft: Java Edition 26.3.
