The second release candidate for 1.0.

## What changed since 1.0.0-rc.1

- **Mineshafts show their tunnels.** The game tries a mineshaft in every
  chunk and each one spreads up to about 100 blocks, so a dozen markers
  could seem to point at one big mineshaft. Zoomed in (from 50%), each
  mineshaft now draws its tunnels seen from above, where the game builds
  them, so you can see which mineshaft is which and where they cross.
  Pointing at a tunnel shows its mineshaft; the selected one is drawn in the
  accent color, and the inspector gives its number of pieces and its area.
  The pieces come from the same game-checked port that places the
  mineshafts.

No change to which structures generate: the map and the finder find exactly
what 1.0.0-rc.1 found. The command line and its formats are unchanged.

Matches Minecraft: Java Edition 26.3.

## Found a problem?

Open an issue with the seed, the dimension, the position and what the game
shows there. A difference from the game is a bug, whatever its size.
