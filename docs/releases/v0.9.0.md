End gateways, and a user guide.

## What's new

- **The 20 End gateways.** The End map shows the gateways around the main
  island, each with its number: the order in which they open, one per dragon
  defeat. The positions are the same for every seed; the order comes from the
  seed, exactly as the game shuffles it. Checked against the game on 400
  seeds and on every seed of the large-scale check.
- **Return gateways.** The gateways on the outer islands that lead back to
  the main island, a new "Return gateways" layer on the End map. The game
  places them as decoration of the End Highlands, about one chunk in 700, 3
  to 9 blocks above the ground. Chunkscope finds the exact block: checked
  against the game's own placement code over whole regions, in the
  large-scale check, and on a real server.
  - Under an end city the gateway can sit higher, because the city's blocks
    are placed first and raise the ground. Those gateways are marked ("an
    end city may raise it" in the app, `under_city` in the JSON); x and z are
    still exact, the height is a lower bound.
  - Not covered: the gateway the game creates far out when someone first
    goes through one of the 20. Where the 20 lead is planned for 1.1.
- **The command line lists both.** `structures --dimension end` prints
  `end_gateway` (with its `order`) and `end_gateway_return` (with its `y`
  and `under_city`). JSON fields are only added, as `docs/FORMATS.md`
  promises.
- **A user guide**, `docs/GUIDE.md`: the map, what each marker promises, the
  seed finder, the command line and the limits.

The rest of the map and the finder find exactly what 0.8.0 found.

Matches Minecraft: Java Edition 26.3.
