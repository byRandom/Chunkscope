Mineshafts, and settings that stay.

## What's new

- **Mineshafts are checked like the game does.** A mineshaft's height
  comes from its corridors, crossings and stairs, so Chunkscope now
  generates them the way the game does and checks the biome where the
  mineshaft really ends up, badlands mineshafts included.
- **No more "possible" markers.** Every structure on the map and in the
  seed finder is now validated against biome and terrain. Only the world
  spawn block is still an estimate (trees and lakes can move it).
- **The app remembers your settings**: the seed, the dimension, where the
  map is and how far it is zoomed, which layers are shown, and the seed
  finder's last query. Settings from this version keep working when later
  versions add new layers.

Every new piece is verified against the real game, bit for bit, by the
oracle tests: 800 whole mineshafts (101,148 pieces) and 2,160 mineshaft
generation points of both types, on top of the mineshaft attempts that were
already in the structure fixtures.

Matches Minecraft: Java Edition 26.3.
