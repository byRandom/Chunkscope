The world spawn and a seed finder.

## What's new

- **World spawn.** A new "World spawn" layer marks where players appear.
  The point the game searches the spawn around is computed from the climate
  exactly like the game. The final block is an estimate: compared with 32
  real 26.3 servers, x and z match on 31 of them, and the height on 23 (the
  real spawn is sometimes on top of a tree, which Chunkscope does not
  generate; the server itself can pick a different height from one run to
  the next).
- **Seed finder.** The new **Finder** tab searches seeds for structures
  near the spawn (or near 0, 0): for example "a village within 300 blocks
  and a pillager outpost within 500". Every structure is checked against
  biome and terrain, like on the map. You can also require a biome at the
  spawn, search seeds in order or at random, and stop at any time. Click a
  result to open it on the map.
- The finder also works from the command line:
  `cargo run --release -p mc-core --example find -- villages:300`.
- Switching seeds is faster (the biome lookup tree is built once).

Matches Minecraft: Java Edition 26.3.
