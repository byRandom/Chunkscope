The first release candidate for 1.0.

Everything the 1.0 criteria ask for is in place (see `docs/ROADMAP.md`): the
Overworld, the Nether and the End match the game bit for bit and are
verified by oracle tests, the large-scale check is clean, settings are saved,
the command line and the formats are stable, and the user guide describes
every feature. This candidate is for trying it out: from here until 1.0 only
fixes go in, no new features.

## What changed since 0.9.0

- The README's status list and crate table match what Chunkscope does; the
  plans after 1.0 (large biomes and amplified presets, where the End gateways
  lead, Bedrock) are listed there.
- The code documentation builds without warnings, and CI keeps it that way.

No change to world generation: the map and the finder find exactly what
0.9.0 found.

Matches Minecraft: Java Edition 26.3.

## Found a problem?

Open an issue with the seed, the dimension, the position and what the game
shows there. A difference from the game is a bug, whatever its size.

`SHA256SUMS.txt` lists the checksums. The binaries are not signed: on
Windows, SmartScreen may ask for confirmation ("More info", then "Run
anyway"); on macOS, run `xattr -d com.apple.quarantine chunkscope` first.
